

## Fluid 상단 필과 메타데이터 (2026-11-10)

기본 정보 필을 계속 표시한다. `06 슬롯` 토글은 같은 navigation pill 규격을 쓰며, 별도의 `i` 필은 기존 Project·Branch·Permission·Context 컨트롤을 컴포저 위 카드로 연다. native 컨트롤의 DOM과 메뉴 동작은 유지하고 footer는 화면 아래 공간을 차지하지 않는다. Escape·바깥 누르기로 카드를 닫는다. 음성 진입 중에는 기존 정보 상태를 보존해 종료 후 복원한다.

`+`는 기본 버튼과 12px 기호를 유지하며 45도 회전만 한다. 옵션 열기에서는 기존 상단 필을 200ms·45ms 간격으로 순차 fade out한 뒤 옵션이 opacity 0에서 460ms droplet·45ms 간격으로 등장한다. 비활성 항목의 기본 불투명도는 유지한다. 기존 필은 열린 동안 inert이며 닫기·해제 때 복원한다. 직접 조작은 옵션 등장을 즉시 끝내며 reduced motion은 등장·퇴장을 즉시 끝낸다. 새 관찰자나 반복 frame loop는 추가하지 않는다. 이 절은 이전 정보 숨김·기호 확대·pressPop 규칙을 대체한다.


### 임시 공통 행 배치

`06 슬롯`과 `i` 필은 기존 Code·Child·Parent 정보 필과 같은 행 안에 둔다. 같은 460ms·45ms droplet으로 등장하며 정보 행의 가용 폭에서 두 필의 자리를 뺀다. 정보 행의 생성·교체·숨김을 해당 컴포저 안에서만 확인하고, 정보 행이 없거나 숨겨진 때만 원래 상단 자리로 돌아간다. 초안·첨부·호스트 메뉴는 유지한다.
