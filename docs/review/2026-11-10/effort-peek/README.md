# Effort 아이콘과 임시 이름 검수

제품 코드: 독립 Composer `d792a7fde14ed4fe5285fd23398b362b877e0c11`, 로컬 정본 `4c4394f61255be5008f7eda16c9a8b25da7a0661`.

기존 표시 모드의 한 줄에서는 Effort 아이콘만 표시한다. 클릭으로 확정한 이름은 기존 글자 효과로 1.5초 동안 표시한 뒤 접는다. 연속 클릭은 시간을 갱신하며 여러 줄은 이름을 계속 표시한다. 전체 Effort 이름은 버튼의 접근성 이름에 남긴다.

- 독립 Composer Node 29개, Composer 279개 통과(기존 3개 skipped 유지). 로컬 Composer 255개·배치 4개와 최종 Effort 13개 통과. 타입 검사와 각 빌드 통과.
- 클릭 결과, 연속 클릭의 시간 갱신, 대화 전환·복귀와 예약 해제, 모델 목록 1회 읽기, 초안 유지, 줄바꿈 경계 복귀와 직접 줄바꿈 보존을 검증했다. 이름 표시 조건을 반대로 바꾼 실험은 테스트 1개가 실패했고 원본을 복원했다.
- 실제 제품의 Chrome desktop·phone 문맥에서 접힘 36px → 이름 펼침 약 68px → 접힘 36px을 확인했다. 동작 줄이기는 전환 없이 상태를 반영한다. 전송과 브라우저 오류는 0회였다. Aside에서도 실제 클릭과 확정된 이름·초안을 확인했다.
- 경계 길이에서는 이름이 보이는 동안 잠시 여러 줄로 펼쳐질 수 있다. 1.5초가 지나면 아이콘을 기준으로 다시 한 줄로 돌아온다. 직접 입력한 줄바꿈은 유지한다. 새 관찰자·반복 frame loop 없이 기존 배치 예약을 사용한다.

[수치 기록](validation.json). 검수 데모는 실제 제품 컴포넌트와 정보 필 스타일을 쓰고, 호스트 목록·아이콘·외부 액션에 검수 데이터를 주입했다. 캡처 하단에 정본 커밋을 표시했다.

현재 BB는 정본 `4c4394f`의 번들 `eedc1ec58d01a65a`를 실행한다. 독립 Composer PR로 실행 소스를 바꾸지 않았다. 실제 iPhone Safari·IME·마이크·외부 전송은 확인하지 않았다. 화면 적합성은 사용자 검수 대상이다.

추가 전체 검증: 정본의 Node 테스트 **790개가 순차 실행(--test-concurrency=1)에서 모두 통과**했다. 첫 병렬 실행에서는 기존 정보 카드 테스트 2개가 실패했으며, 소스나 단언을 바꾸지 않은 단독 재실행 2개와 순차 전체 실행에서 통과했다.
