# 임시 공통 정보 행 검수

검증 코드: Composer `66e8fb4`, Chat UI `00cd16d`, 조합한 로컬 정본 `4f4274`.

06 슬롯과 i 필을 코드·Child·Parent 등 기존 정보 필과 같은 행 안에 배치했다. 같은 460ms·45ms 물방울 등장과 + 옵션 전환을 유지하며, 정보 행이 없을 때만 원래 위치로 돌아간다. 임시 필을 뺄 때 기존 행의 가용 폭도 복원한다.

- 정본 Node 전체 788개 통과 및 추가 폭 예약 회귀 1개 통과. Composer 전체 회귀 후 변경한 정보 행·메타데이터 경로 17개 재검증 통과.
- 독립 Composer 전체 278개 통과(기존 3개 skipped 유지), 최종 정보 경로 17개 재검증 통과. 각 타입·빌드 통과.
- 행의 늦은 생성·교체·숨김·복귀·unmount, 같은 편집기와 초안 유지, 접힌 호스트의 i 카드, 폭 예약·해제를 검증했다. 행 선택 조건 반전 시 새 테스트가 실패했고 원본을 복원했다.
- Chrome desktop·phone 문맥에서 필들의 높이와 세로 좌표가 같고, 70프레임 중 기존 필이 사라지기 전 옵션이 보인 프레임은 0개였다. 정보 카드·기본 + 크기·reduced motion도 유지했다. Aside에서도 같은 행 연결과 초안 보존을 확인했다.
